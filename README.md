# ARHA/MUSI 274: EXPERIMENTAL ELECTRONIC INSTRUMENTS

Learn digital audio synthesis and build experimental physical interfaces using [plugdata](https://plugdata.org/) and the [Daisy Seed](https://daisy.audio/products/seed3). Developed by Brian House and Amherst students on amazing open-source platforms.


### [Syllabus](SYLLABUS.md)

The syllabus, readings, and schedule for the Amherst College course.


### [`ac/` Pd Externals Library](https://github.com/brianhouse/ac)

The library of compileable, Pd-vanilla objects used in the workshops.
